# Layout

[Back to the README](../README.md)

- `src/TinyMobi.h` - the whole library
- `src/TinyMobi/MobiReaderApp.h` - optional reader GUI for TinyMaterialDesign
- `examples/gui-reader/` - reader GUI as a desktop program
- `tools/gui-screenshots/` - saves screenshots of the reader GUI as BMP images
- `tests/test_tinymobi.cpp` - desktop tests
- `cmake/Emulator.cmake` - fetches the Arduino emulator for the examples
- `examples/serial-reader/` - Arduino example (`.ino`, and the CMake file for the
  desktop build)
- `docs/` - documentation
