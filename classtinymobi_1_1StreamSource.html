Detailed Description

template<typename File>
class tinymobi::StreamSource< File >

Source backed by any seekable file with size(), seek(pos) and read(buf, n), e.g. Arduino File (SD, LittleFS, FFat, SPIFFS), SdFat FsFile, ... The file must stay open while the document is used.
