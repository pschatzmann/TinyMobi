◆ TextMode

enum class tinymobi::TextMode : uint8_t
strong

Output mode of the text stream.

Enumerator
Markup 

raw book markup (HTML-like tags kept), UTF-8 encoded

Plain 

tags removed, block tags become '
', entities decoded

PlainLinks 

Plain text where each link is marked: "\x01" + target + "\x02" + link text + "\x03". The target is the value that resolveLink() accepts. Links to other places (mailto:, http:) are not marked. Headings (h1-h6) are wrapped in "\x04" ... "\x05" on their own lines.
