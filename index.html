TinyMobi

Introduction

TinyMobi is a header-only MOBI / PalmDOC parser for Arduino and desktop C++. It is designed for document readers on microcontrollers: the book is streamed from memory or from an SD card, one record at a time, into a fixed buffer.

Features

Small footprint

  • Header only: #include <TinyMobi.h>, no heap allocation.
  • The file is never loaded completely. Headers, metadata and the record table are read on demand.
  • Text is decompressed one record at a time into a fixed buffer (RecordBufferSize, default 4096 bytes).
  • Works with memory buffers (MemorySource) and any seekable file (StreamSource<File>: SD, LittleFS, FFat, SPIFFS, SdFat).

Formats and text

  • Compression: PalmDOC (LZ77), HUFF/CDIC and uncompressed, with trailing entries and multibyte overlap.
  • KF8 (AZW3 and hybrid MOBI): the XHTML parts are assembled from the skeleton and fragment tables and read like any other text. The output is byte identical to KindleUnpack on the test books.
  • One text stream for every format: read() delivers the book in reading order.
  • UTF-8 output; CP1252 books are converted on the fly.
  • Markup mode (raw HTML-like book text) or plain text mode (tags removed, block tags become newlines, entities decoded).
  • Bookmarks: position() and seek() work with section-based positions.

Book structure

  • Metadata: title, author, publisher, language, date, cover record.
  • Table of contents (NCX index): titles, start positions, levels and the tree. The start positions are not available for KF8 books (see the limitations).
  • Links in the text (filepos and kindle:pos) resolve to positions with resolveLink(), also in KF8 books.
  • Image references in the text (<img recindex> and kindle:embed).
  • Raw access to any PalmDB record with readRecord() and recordLength(). imageType() recognizes JPEG, PNG, GIF and BMP data, so covers can be saved.

Reader GUI (optional)

Built on TinyMaterialDesign and TinyFonts, see src/TinyMobi/MobiReaderApp.h.

  • Page-by-page reading with swipe navigation.
  • Tappable links: the table of contents is part of the text.
  • Headings, a title bar with the page number, and the JPEG cover on the first page.
  • A system menu with a settings screen: dark mode, navigation buttons, page number.

Limitations (DRM, images are not decoded, and others) are listed in Limitations.

Installation in Arduino

You can download the library as zip and call include Library -> zip library. Or you can git clone this project into the Arduino libraries folder e.g. with

cd ~/Documents/Arduino/libraries
git clone https://github.com/pschatzmann/TinyMobi.git

I recommend to use git because you can easily update to the latest version just by executing the git pull command in the project folder.

Then add #include <TinyMobi.h> to your sketch. See the usage guide and the serial-reader example.

For desktop builds with CMake, see Desktop build and tests.
