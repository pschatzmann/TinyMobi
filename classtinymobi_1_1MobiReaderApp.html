Detailed Description

template<typename RGB_T = TINYMD_DEFAULT_RGB_T, typename Doc = MemoryMobi>
class tinymobi::MobiReaderApp< RGB_T, Doc >

The book reader GUI for TinyMaterialDesign: a full screen JPEG cover, then the book text one page at a time.

  • Cover: the JPEG cover of the book (if it has one), shown full screen before the first page. A tap or a swipe to the left opens the text.
  • Text: a title bar with the book title, the page number (optional, see the settings) and a system menu (the menu icon in the title bar), and the text of the page. Pages are turned by swiping left (next) and right (previous). The Previous and Next buttons are optional (see the settings).
  • System menu: "Go to start", "Bookmarks" (add the shown page, jump to saved bookmarks), "Settings", "About" (author, publisher and language) and, if onClose is set, "Close". The table of contents is part of the text: its links jump to the chapters (see TextMode::PlainLinks).
  • Settings: dark mode (on by default) and navigation buttons (off by default).

The page text is read from the document with read() in plain text mode and cut so that it fits the text area. Each page start is remembered, so previous() works after next(). goTo() starts a new page sequence, e.g. at a table of contents entry.

Usage:

tinymobi::FileMobi<File> doc{tinymobi::StreamSource<File>(file)};
tinymobi::MobiReaderApp<RGB565, tinymobi::FileMobi<File>> gui(DefaultBoard, doc);
void setup() {
doc.open(); // the document must be open
gui.begin();
}
void loop() { gui.update(); }

Limitations: the text pages are not scrolled. A single word that is taller than the text area is clipped. At most kMaxPages pages can be reached. Bookmarks are kept for the session only. Links that cannot be resolved are shown as plain text.
