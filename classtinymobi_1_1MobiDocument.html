Detailed Description

template<typename Source, size_t RecordBufferSize = 4096, bool WithKf8 = true>
class tinymobi::MobiDocument< Source, RecordBufferSize, WithKf8 >

MOBI document parser and text stream.

Template Parameters
Sourceone of MemorySource, StreamSource<File> or a custom type with the interface described above
RecordBufferSizesize of the decompression buffer in bytes. It must be >= the largest uncompressed text record (4096 for virtually all books).
